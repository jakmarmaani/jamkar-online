# JamKar Online

A child-safe educational game platform created for **jamkar.online**.

## Current playable release

- Six original browser games
- Adventure, English, maths, building, memory and environmental challenges
- Original animation and synthesised sound effects
- Keyboard, touch and mobile support
- Device-saved scores

## Production account model

- Parent registration by email and password
- One £4.99 lifetime purchase per parent email
- Maximum of two unique child usernames per parent account
- Separate progress for each child
- Parent recovery and account controls
- Child profiles never expose the parent's email

## World roadmap

Each world is designed for 30 progressive levels: Prehistoric Earth, Deep Ocean, Ancient Civilisations, Nature, Deep Space, Future City, English, Mathematics, Science, Logic, Puzzles, and Time Builder—from prehistory to the future.

## Security

Passwords and Revolut payment confirmation require a secure server and database. They must never be stored in browser code or committed to this repository.
